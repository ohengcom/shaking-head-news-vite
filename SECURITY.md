# Security Policy

## Supported Versions

Security fixes target the current `main` branch and the latest tagged release.
Older self-hosted deployments should upgrade to the latest release before reporting
an issue as reproducible.

## Reporting A Vulnerability

Please report sensitive issues through GitHub Security Advisories:

https://github.com/ohengcom/shaking-head-news-vite/security/advisories/new

Include the affected route or feature, reproduction steps, expected impact, and any
relevant environment details. Avoid posting exploit details in public issues.
